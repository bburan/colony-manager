# The breeding list

One row per breeding pair, active pairs first, most recently created
first within each group.

| Column | Meaning |
|---|---|
| **ID** | the pair's ID, which is also the ID of the cage it lives in |
| **Male** / **Female** | the two animals, linked to their animal pages |
| **Start Date** | when the pair was put together |
| **Total Litters** | every litter ever recorded for the pair |
| **To Wean** | litters with no wean date recorded yet |

Click the pair ID to open it and record litters.

## Creating a pair

The heart button opens the new-pair form. For each parent you can either
pick an **existing animal** from the dropdown, or leave it blank and fill
in the species, date of birth, source and notes to create a new one. A
newly created parent is named after the pair with a `-M` or `-F` suffix —
a pair called `G100` gets animals `G100-M` and `G100-F`.

Creating a pair also creates **a new cage** with the pair's ID and moves
both parents into it.

The male and the female must be the same species; the form is rejected
otherwise.

> Breeding pairs are deactivated rather than deleted, which keeps the
> parentage of every animal they produced intact.
