# The calendar

Every animal event in the database, on a month grid or as an agenda list.
Switch between the two with the **Grid** / **Agenda** buttons.

## Where an event lands

An event has a scheduled date and, once done, a completion date. The
calendar places it on:

- its **completion date**, drawn in green, if it has been completed;
- otherwise its **scheduled date**, drawn in blue.

So a procedure that slipped moves from its planned day to the day it
actually happened, rather than appearing twice.

## Merged bars

Entries are grouped by procedure, not by animal — a single bar reads
"Noise exposure" rather than listing twenty animals. Consecutive days are
merged into one bar when the procedure, the status *and the exact set of
animals* all match. A different set of animals on the next day starts a
new bar, so a merged bar always describes one cohort doing one thing.

## Reading a bar

- **Hover** — the animals in that bar, as a tooltip.
- **Click** — a list of those animals; each entry links to its animal page.

The calendar is read-only. Schedule and complete events from the
[animal page](/help/animal-detail).

> The calendar is not filtered by the species selector — it shows every
> event in the database.
